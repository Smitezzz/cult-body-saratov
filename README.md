# Cult Body

Премиальный адаптивный сайт студии эстетики тела Cult Body.

## Локальный запуск

1. Установите Node.js 22 или новее.
2. Установите зависимости: `npm install`.
3. Запустите сайт: `npm run dev`.
4. Откройте адрес, который появится в терминале.

Для итоговой проверки используйте `npm run build`.

## Структура

- `app/page.tsx` — главная страница и контент.
- `app/components/` — интерактивные блоки записи, FAQ и сравнения результата.
- `app/globals.css` — дизайн-система, анимации и адаптивность.
- `public/og.png` — брендированное превью для соцсетей.
